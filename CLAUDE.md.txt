# MASTER PROJECT PROMPT
## Build a Production-Ready Full-Stack E-Commerce Platform

Act as a Senior Software Architect, Senior Full-Stack Engineer, UI/UX Designer, Database Architect, Security Engineer and QA Engineer.

Your task is to design and develop a modern, premium, production-ready e-commerce platform using Next.js.

# 7. RAZORPAY PAYMENT INTEGRATION

This is a critical module. Implement it carefully.

Payment workflow:

Step 1:
Customer adds products to cart.

Step 2:
Customer proceeds to checkout.

Step 3:
Backend fetches current product prices from MongoDB.

Step 4:
Backend calculates the actual payable amount.

Step 5:
Create a pending order and Razorpay order through the server.

Step 6:
Open Razorpay Checkout.

Step 7:
Customer completes payment.

Step 8:
Backend verifies Razorpay payment signature.

Step 9:
Verify payment status and amount.

Step 10:
Process Razorpay webhooks.

Step 11:
Update payment and order status.

Step 12:
Update inventory safely and display the confirmed order in the admin dashboard.

Important security requirements:
- Never trust frontend payment amounts.
- Never mark an order as paid based only on a frontend callback.
- Verify payment signatures on the server.
- Verify webhook signatures using the raw request body.
- Handle duplicate webhook events idempotently.
- Handle delayed payment confirmations.
- Handle failed payments.
- Handle payment retries.
- Implement refund tracking.
- Prevent duplicate stock deductions.
- Store Razorpay identifiers in MongoDB.
- Never expose Razorpay secret keys.

Support Razorpay test mode first.

Do not switch to live payments until the complete payment flow has been tested.
